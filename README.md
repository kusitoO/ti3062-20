Problemática

En una bodega minera simulada, el personal de bodega necesita registrar los
movimientos de piezas de tubería prearmadas, llamadas spools. El equipo de
montaje necesita consultar dónde se registró cada pieza por última vez y
cuándo se entregó a terreno.

Componentes del proyecto

Aplicación de inventario en AWS Academy. Registra recepciones, traslados
  y entregas. Permite buscar un spool por su código y ver su historial y su
  última ubicación registrada. Usa datos ficticios.
Sistema de gestión en Cloudflare Pages. Registra la planificación,
  los requerimientos, los controles de seguridad y las evidencias. Genera
  el PDF de la evaluación a partir de los datos registrados.
